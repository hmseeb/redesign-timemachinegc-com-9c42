# Time Machine Contracting & Restoration — Website Redesign

A ground-up redesign of timemachinegc.com built with vanilla HTML, CSS and JavaScript
(no build step, no dependencies, no external APIs).

## Business

**Time Machine Contracting & Restoration** — water, fire, mold, storm and biohazard
restoration, plus remodeling, reconstruction and floor cleaning for homes and businesses
across Orlando and Central Florida.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Single-page site — semantic HTML, meta/OG/Twitter tags, LocalBusiness JSON-LD (3 offices) |
| `styles.css` | Design system: CSS custom properties, responsive grid layouts, mobile action bar, reduced-motion support |
| `script.js` | Sticky header + scrollspy, mobile nav, scroll reveal, LeadrVision form handling |
| `favicon.svg` | Monogram favicon placeholder (clock/time-machine mark) |

## Page sections

Hero → value props → 9 services → 4-step process → our work gallery → 10 service areas
+ 3 offices → customer review → 6 news articles → contact + quote form → footer with
newsletter signup.

## Forms

Both forms (quote request and newsletter) POST to LeadrVision:
`https://vision.leadrai.com/api/forms/18d2d1bbd1574dc297033baeb6ffddd3`

* hidden `_form` names the form ("Quote request", "Newsletter")
* hidden `_page` is set to `window.location.href` on page load and on submit
* hidden `_gotcha` honeypot guards against bots
* fields use human-readable names; `name`, `email`, `phone` where applicable
* no-JS fallback performs a normal POST and returns to the page with `?submitted=1`,
  which shows the "Thanks, your message was sent" confirmation
* with JS, the form is submitted via `fetch()` as JSON to the same endpoint and shows
  the same confirmation inline; on network failure it falls back to the plain POST
